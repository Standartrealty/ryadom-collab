# Рядом — коллаборации в Дагестане

Первая версия площадки для компаний, блогеров и специалистов Махачкалы, Каспийска и других городов Дагестана. Рабочее название — «Рядом».

## Возможности

Открытый каталог с фильтрами и отдельными профилями, доска предложений, Telegram/WhatsApp, двухшаговая подача профиля с изображением, подача объявления, запросы на изменение, серверная модерация, справочники, история и экспорт. Шесть явно обозначенных вымышленных профилей и четыре демопредложения. У демо нет реальных контактов.

## Технологии

Node.js 24, серверный HTML, ES modules, CSS, Vercel Functions, приватный Vercel Blob. Каждая заявка и изменение записываются отдельным неизменяемым JSON-событием. Публичный API возвращает только разрешённые поля. Записи не зависят от файловой системы serverless-функции. Для небольшого старта это простой вариант постоянного хранения; при росте перейти на SQL, не меняя публичную модель данных.

## Локальный запуск

`pnpm install`, `pnpm build`, `pnpm dev`. Открыть http://127.0.0.1:4199. Локальный сервер использует `.local-data/`, не production-хранилище. `pnpm test` проверяет валидацию, приватность, фильтрацию и доступ к черновикам. `pnpm check` проверяет синтаксис.

## Настройки Vercel

Build: `node build.mjs`, output: `public`, runtime: Node.js 24, region: fra1. Приватный Blob подключён к проекту. Серверу нужны `BLOB_STORE_ID` либо `BLOB_READ_WRITE_TOKEN`, `ADMIN_PASSWORD_HASH` (SHA-256 случайного пароля), `ADMIN_SESSION_SECRET`. Секреты задаются в настройках окружения Vercel и не коммитятся. Для нового окружения создавайте отдельное хранилище и отдельные секреты. Не используйте production-заявки в тестах.

## Администратор

Вход `/admin`, сессия 8 часов, HttpOnly/SameSite cookie. Первичный пароль сохранён владельцу только в игнорируемом локальном `.admin-access.txt`. В коде и GitHub пароля нет. Перед публикацией подтвердите сведения и контакт владельца, отметьте проверку. Изменения можно внести в редакторе полей JSON. Для нового участника используйте обычную форму и одобрите заявку. Публикация объявления без профиля создаёт связанный профиль автора. Контакт администрации закрыт.

Вкладки: новые заявки, все записи, справочники, история и экспорт. Архивирование скрывает запись и сохраняет историю. Полное удаление персональных данных требует удаления всех событий соответствующего ID и связанных аналитических событий из приватного хранилища; кнопки необратимого удаления в интерфейсе нет. Сохраняйте приватные экспорты только в защищённом месте. Экспорт можно использовать как резервную копию; автоматическое расписание копирования и восстановление через UI не реализованы.

## Ограничения раннего запуска

Перед массовым приёмом реальных участников заполнить сведения владельца и рабочий канал поддержки, окончательно утвердить правила обработки данных, заменить демо согласованными реальными профилями. География пользователей — Дагестан, текущий регион хранилища — Франкфурт. Сайт не подключает сторонние рекламные трекеры и не проводит платежи. Базовая статистика фиксирует клики контактов и начала форм, без содержимого заявок. Уведомлений в мессенджер пока нет: новые заявки проверяются в панели.

Нет пользовательских кабинетов, внутреннего чата, оплаты продвижения, рейтингов, AI-подбора. Поддерживаются все согласованные форматы через справочник; условия обсуждаются напрямую. Истечение объявлений — 30 дней, дальнейшее продление через модерацию. Заявки на изменения не меняют публикации автоматически.
